## cloud-secure-network-design-educational-context
Secure infrastructure and database architecture design for a debt collection company, including network segmentation, firewall configuration, cloud services, virtualization, SQL database modeling, and secure web-based data management.

# Infrastructure Design
The proposed infrastructure includes:

segmented LAN architecture,
dedicated subnets,
firewall-based traffic filtering,
DHCP and database servers,
wireless guest network isolation,
secure internet access management.

# Network Segmentation
The infrastructure is divided into multiple subnets:

employee network,
server room network,
guest wireless network.

This separation reduces attack surfaces and improves internal security.

# Security Features 
The project includes several cybersecurity-oriented components:

firewall ACL configuration,
network isolation,
controlled routing,
secure server room considerations,
backup strategies,
cloud-based infrastructure advantages,
reduced exposure of internal LAN resources.

# Cloud Computing Integration

The infrastructure evaluates cloud adoption through:

DaaS (Data as a Service),
SaaS (Software as a Service),
virtual servers,
remote backup systems,
web and application servers.

Benefits analyzed:

scalability,
reduced maintenance costs,
improved availability,
disaster recovery support,
infrastructure flexibility.

# Virtualization 
The project also analyzes virtualization technologies for running multiple operating systems on the same host machine without affecting the primary OS.

Technologies discussed:

VirtualBox
Virtual Machines (VMs)
ISO-based OS deployment

# Database Design 
A relational database was designed to manage:

companies,
VAT numbers,
credits,
installment payments,
quarterly deadlines.

The database design includes:

ER modeling,
relational schema conversion,
normalization process (1NF, 2NF, 3NF),
SQL table creation,
data querying.

# Web-Based Data Access

A web interface was designed using:

HTML
PHP
MySQL

The application allows employees to:

input a credit threshold,
retrieve companies with debts exceeding a specified amount,
dynamically query the database.
